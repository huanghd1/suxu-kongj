# suxu-kongj · 深空知识航道

单文件 Three.js 原型：一条深空航道，宇航员自动向前穿越，航道里漂着 61 张知识卡；点开一张，右侧弹出对应的三维坐标图和公式。

## 运行

双击 `index.html` 即可（用的是 UMD 版 three，`file://` 直接开也能跑，不需要构建工具）。

## 玩法

| 操作 | 结果 |
|---|---|
| 自动 | 宇航员沿中间光轨匀速前进，三条流光路向前延伸 |
| W / S、滚轮、上下拖拽 | 手动前进 / 后退，松手平滑回到自动速度 |
| V | 第一人称 / 第三人称切换 |
| 点击知识卡 | 右侧弹出三维坐标视窗（坐标轴 + 网格 + 该知识点的图形，自动旋转） |
| 点击另一张卡 | 直接切换知识点 |
| 点击空白 / ESC / × | 收起，恢复自动飞行 |

知识点数据取自「东东坐标系实验室」的 20 大类 61 个知识点，公式已从 TeX 转成可读文本；每个知识点配了对应的图形（函数曲线、圆锥圆柱球体、参数曲面、二项分布、定积分、洛伦兹吸引子、傅里叶级数等）。

## 可调参数

全部集中在 `index.html` 顶部的 `CONFIG`：

- 天空：`SKYBOX_PATH`（换成自己的天空盒）、`SKY_TINT`、星点密度
- 地球：`EARTH_RADIUS`、`SHOW_DISTANT_PLANET`
- 航道：`LANE_COLORS`、`LOOP_RADIUS_X/Z`、`AUTO_SPEED`、相机距离
- 知识流：`KNOWLEDGE_FLOW`、`KNOWLEDGE_CARDS`

URL 加 `?k=12` 可以直接打开第 12 个知识点。

## 说明

- three.js 通过 unpkg 的 CDN 引入（UMD 版 r159），unpkg 不通时会自动切 jsdelivr。
- 地球是程序化 shader（大陆 / 云层 / 冰盖 / 夜面灯光），不依赖贴图。
- `preview.png` 是实机截图。
